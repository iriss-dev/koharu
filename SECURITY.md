# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Koharu and its users seriously. If you discover a security vulnerability or exploit within Koharu (such as SQL injection vectors, race conditions in the economy engine, or permission escalation bugs in role handling), please do **NOT** open a public issue.

Instead, please send a private disclosure email directly to:

📧 **iriss.smith08@proton.me**

### What to Include
- Detailed description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or proof-of-concept (PoC).
- Suggested remediation or patch if available.

### Our Commitment
- We will acknowledge receipt within 48 hours.
- We will provide a coordinated fix and credit you in release notes (unless anonymity is requested).
